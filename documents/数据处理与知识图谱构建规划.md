# 旅游推荐系统数据处理与知识图谱构建规划文档

## 一、项目背景与目标

### 1.1 项目背景

本项目旨在构建一个基于知识图谱的旅游推荐系统，融合图神经网络（GNN）和大语言模型（LLM）技术，为用户提供智能化的旅游推荐和问答服务。

### 1.2 数据文件概述

本项目使用两个数据文件，分别服务于不同的技术路线：

#### 文件一：scenic_spots_30000.csv（推荐系统专用）
- **用途**：训练GNN推荐模型
- **特点**：轻量级，聚焦图结构和交互关系
- **适用模型**：LightGCN、GCN、GraphSAGE、GAT、KGAT、PinSage

#### 文件二：scenic_spots_30000_llm.csv（智能问答专用）
- **用途**：训练LLM问答模型和RAG系统
- **特点**：扩展字段丰富，支持自然语言理解
- **适用技术**：RAG检索增强、LangChain、向量数据库、微调客服模型

## 三、知识图谱构建方案

### 3.1 Neo4j知识图谱设计

#### 3.1.1 节点类型

| 节点类型 | 说明 | 属性 |
|----------|------|------|
| User | 用户 | user_id, username, profile |
| ScenicSpot | 景点 | spot_id, name, city, type, rating |
| City | 城市 | city_id, name, province |
| SpotType | 景点类型 | type_id, name, description |
| Season | 季节 | season_id, name |

#### 3.1.2 关系类型

| 关系类型 | 说明 | 属性 |
|----------|------|------|
| VISITED | 用户访问过景点 | timestamp, rating, comment |
| LOCATED_IN | 景点位于城市 | - |
| HAS_TYPE | 景点属于类型 | - |
| NEARBY | 景点附近 | distance |
| SIMILAR | 相似景点 | similarity_score |
| SUITABLE_FOR | 适合人群 | season, crowd_type |
| RATED | 用户评分 | rating, timestamp |

### 3.2 数据导入流程

#### Step 1: 环境准备
```bash
# 启动Neo4j服务
neo4j start

# 验证连接
cypher-shell -u neo4j -p password "RETURN 1"
```

#### Step 2: CSV数据导入
```bash
# 使用neo4j-admin导入
neo4j-admin import \
  --nodes=ScenicSpot=scenic_spots_30000.csv \
  --relationships=VISITED=user_spot_interactions.csv
```

#### Step 3: 知识图谱关系构建
```cypher
// 构建城市-景点关系
MATCH (s:ScenicSpot)
MERGE (c:City {name: s.city})
MERGE (s)-[:LOCATED_IN]->(c)

// 构建类型-景点关系
MATCH (s:ScenicSpot)
MERGE (t:SpotType {name: s.type})
MERGE (s)-[:HAS_TYPE]->(t)

// 构建景点相似关系（基于类型和评分）
MATCH (s1:ScenicSpot), (s2:ScenicSpot)
WHERE s1 <> s2 AND s1.type = s2.type
  AND abs(s1.rating - s2.rating) < 0.5
MERGE (s1)-[:SIMILAR {score: 1.0 - abs(s1.rating - s2.rating)}]->(s2)
```

## 六、数据处理代码实现

### 6.1 CSV数据读取与验证

```python
import pandas as pd

def load_scenic_spots(file_path: str) -> pd.DataFrame:
    """加载景点数据"""
    df = pd.read_csv(file_path)

    # 数据验证
    required_columns = ['spot_id', 'name', 'city', 'type', 'rating']
    for col in required_columns:
        if col not in df.columns:
            raise ValueError(f"缺少必需字段: {col}")

    # 数据清洗
    df = df.dropna(subset=['spot_id', 'name'])
    df['rating'] = df['rating'].fillna(0).clip(0, 5)

    return df
```

### 6.2 Neo4j数据导入

```python
from neo4j import GraphDatabase

class Neo4jDataImporter:
    def __init__(self, uri, user, password):
        self.driver = GraphDatabase.driver(uri, auth=(user, password))

    def import_scenic_spots(self, df):
        """导入景点数据到Neo4j"""
        with self.driver.session() as session:
            for _, row in df.iterrows():
                session.run("""
                    MERGE (s:ScenicSpot {spot_id: $spot_id})
                    SET s.name = $name,
                        s.city = $city,
                        s.type = $type,
                        s.rating = $rating
                """, **row.to_dict())

    def build_relationships(self):
        """构建知识图谱关系"""
        with self.driver.session() as session:
            # 城市-景点关系
            session.run("""
                MATCH (s:ScenicSpot)
                MERGE (c:City {name: s.city})
                MERGE (s)-[:LOCATED_IN]->(c)
            """)

            # 类型-景点关系
            session.run("""
                MATCH (s:ScenicSpot)
                MERGE (t:SpotType {name: s.type})
                MERGE (s)-[:HAS_TYPE]->(t)
            """)
```

### 6.3 用户交互数据生成

```python
def generate_user_interactions(spots_df, num_users=1000, interactions_per_user=10):
    """生成模拟用户交互数据"""
    import random

    interactions = []
    user_ids = [f"user_{i}" for i in range(num_users)]

    for user_id in user_ids:
        # 随机选择交互的景点
        visited_spots = random.sample(
            spots_df['spot_id'].tolist(),
            interactions_per_user
        )

        for spot_id in visited_spots:
            rating = random.uniform(3.0, 5.0)
            interactions.append({
                'user_id': user_id,
                'spot_id': spot_id,
                'rating': rating,
                'timestamp': pd.Timestamp.now()
            })

    return pd.DataFrame(interactions)
```
